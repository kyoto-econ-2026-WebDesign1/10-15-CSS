## 💡 CSSの基本文法（3点セット）

CSSは **「誰に（セレクタ）」「何を（プロパティ）」「どうする（値）」** の3つで書きます。

```css
h1 {
    color: brown;
}
/* 誰に(h1) { 何を(文字色を): どうする(茶色に); } */
```

- 末尾のセミコロン（`;`）を忘れがちなので注意しましょう。
- 色は `#xxxxxx` のような複雑なコードではなく、**`brown` や `beige` などの英語名** で指定できます。

## 📦 超重要：ボックスモデル（余白の使い分け）

Webページのすべての要素は「四角い箱（ボックス）」です。初心者が最もつまずきやすい **`padding` と `margin` の違い** を押さえましょう。

```text
+---------------------------------------------------+
| margin (外側の余白) : 他の要素とのすき間          |
|   +-------------------------------------------+   |
|   | border (枠線)                             |   |
|   |   +-----------------------------------+   |   |
|   |   | padding (内側の余白) : 息抜き空間 |   |   |
|   |   |   +---------------------------+   |   |   |
|   |   |   | コンテンツ (文字や画像)   |   |   |   |
|   |   |   +---------------------------+   |   |   |
|   |   +-----------------------------------+   |   |
|   +-------------------------------------------+   |
+---------------------------------------------------+
```

- **`padding`**: 箱の「内側」の余白。文字と枠線の間にゆとりを持たせます。
- **`margin`**: 箱の「外側」の余白。隣の箱との間隔を空けます。
- **`margin: 40px auto;`**: 左右を `auto` にすると、ブラウザが自動計算して **画面のど真ん中に中央寄せ** してくれます。

## ✨ 覚えておきたいCSSの技・見どころ

| コード | 役割 | 解説 |
| :--- | :--- | :--- |
| `display: flex;` | 横並びの魔法 | ナビゲーションのリンクを一瞬で横一列に並べます |
| `justify-content: center;` | 中央寄せ | 横並びにしたメニュー項目を画面の真ん中に集めます |
| `:hover` (擬似クラス) | マウス乗せ効果 | マウスカーソルが乗った時だけ色を変えて「押せるボタン」だと伝えます |
| `list-style-type: '☕ ';` | 絵文字マーカー | リストの「・」を好きな絵文字（コーヒーカップ）に変えられます |
| `box-shadow: 0 4px 10px lightgray;` | 立体感・影 | 白いカードの下に薄い影を落として、浮き上がったように見せます |

## 🎨 カフェの模様替え遊び

「お店の雰囲気を変えてみましょう！色を変えるだけで、まったく別のお店に変身します。」

- **抹茶カフェ・和カフェにしたい場合**:
  - `brown` → `darkgreen` または `forestgreen`
  - `chocolate` → `olivedrab`
  - `beige` → `honeydew` または `seashell`
- **夜カフェ・バー風にしたい場合**:
  - `brown` → `midnightblue` または `navy`
  - `chocolate` → `darkslateblue`
  - `beige` → `whitesmoke`
- **紅茶・いちごスイーツカフェにしたい場合**:
  - `brown` → `crimson` または `firebrick`
  - `chocolate` → `coral`
  - `beige` → `mistyrose`
